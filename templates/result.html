  • AES (Advanced Encryption Standard): AES is a symmetric encryption algorithm that uses 128-bit, 192-bit, or 256-bit keys to encrypt data. It is widely used for securing data in transit and at rest. This method tries all possible key combinations to decrypt the content.
  • DES (Data Encryption Standard): DES is an older symmetric encryption standard using a 56-bit key. It encrypts data in 64-bit blocks. While no longer recommended for modern security standards, it may still be used in legacy systems. The tool attempts to decrypt data by testing all 56-bit keys in a brute-force manner.
  • Blowfish: Blowfish is a fast, symmetric encryption algorithm designed to be secure and efficient with key sizes ranging from 32 bits to 448 bits. The tool attempts to crack the PDF password by trying every possible key in a brute-force attack, making it a robust method for securing sensitive information.
  • ChaCha20: ChaCha20 is a modern stream cipher designed by Google that offers high speed and security. It is particularly efficient on modern hardware and can handle high-throughput operations effectively. The tool employs brute-force methods to test all possible keys until the correct one is found.
