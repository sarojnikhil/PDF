PDF Password Cracker

This is an ethical hacking project designed to demonstrate password recovery techniques for PDF files. The tool uses various methods including dictionary attacks and brute force to attempt password cracking. Please use this tool responsibly and ethically, only with your own documents.

How does it work?

  • Step 1: Upload the encrypted PDF file. This file will be scanned for any password protection.
  • Step 2: The tool attempts to crack the PDF password using a **dictionary attack**, where a pre-built list of common passwords is checked against the encrypted document. If no matches are found, it proceeds to **brute-force attacks**, systematically trying all possible combinations of characters.
  • Step 3: If the PDF contains encrypted text, the tool uses different decryption algorithms to attempt to decrypt the content and reveal the original text. These algorithms include **AES (Advanced Encryption Standard)**, **DES (Data Encryption Standard)**, **Blowfish**, and **ChaCha20**.

Ethical Note: This is an ethical hacking project. The tool should only be used on your own PDF documents. Unauthorized use on others' documents is illegal and unethical. The purpose of this tool is to educate on password cracking techniques, not for malicious intent.
